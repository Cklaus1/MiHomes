# Daily Operations Playbook

**Type**: daily  
**Owner**: Lead Housekeeper  
**Properties**: all  
**Estimated time**: 3–4 hours (full house)

This playbook defines the baseline daily routine. Every day the house is occupied, this runs in full. When unoccupied, run the abbreviated version (marked below).

---

## Morning Opening (7:00–9:00 AM)

### Exterior
- [ ] Unlock and inspect main entry
- [ ] Check exterior doors and windows are secure overnight
- [ ] Retrieve any packages or deliveries from entry
- [ ] Check driveway / parking area — clear and presentable

### HVAC & Systems
- [ ] Set HVAC to occupied schedule (per season)
- [ ] Check thermostat — confirm target temp is reached
- [ ] Check water heater status if applicable
- [ ] Turn on house lighting as needed per time of day

### Kitchen
- [ ] Unload dishwasher (if run overnight)
- [ ] Wipe counters and sink
- [ ] Check fridge: discard anything expired, wipe spills
- [ ] Restock coffee, water, fruit bowl if low
- [ ] Empty trash if >50% full
- [ ] Check supply levels: dish soap, paper towels, sponge

### Common Areas
- [ ] Plump and arrange sofa cushions and throw pillows
- [ ] Clear any items left out overnight — return to correct rooms
- [ ] Wipe dining table
- [ ] Ensure TV remotes, chargers are in designated spots
- [ ] Open blinds / curtains per resident preference

---

## Midday Refresh (12:00–1:00 PM) — occupied only

- [ ] Kitchen wipe-down after lunch
- [ ] Spot check bathrooms (towels, toilet, surfaces)
- [ ] Empty kitchen trash if needed
- [ ] Replace any towels left on floor
- [ ] Walk common areas — tidy and reset

---

## Evening Close (7:00–9:00 PM or before last staff leaves)

### Kitchen
- [ ] Full wipe of all counters and stovetop
- [ ] Load and run dishwasher
- [ ] Empty trash
- [ ] Sweep / mop floor
- [ ] Confirm fridge is closed properly

### Common Areas
- [ ] Reset all common areas to standard layout
- [ ] Turn off non-essential lights
- [ ] Confirm exterior doors locked
- [ ] Lower blinds / close curtains as preferred

### HVAC & Systems
- [ ] Set HVAC to night/away schedule
- [ ] Confirm security system is armed (if applicable)
- [ ] Do a final walk — check all rooms, lights off

---

## Unoccupied Day (abbreviated)

- [ ] Morning systems check (HVAC, water, security)
- [ ] Exterior check
- [ ] Kitchen check — no spills, fridge secure
- [ ] End-of-day walk and lock-up

---

## Issue Reporting

If anything is broken, missing, or needs attention:
1. Log it in MiHomes: `mihomes issue add --property <slug> --title "..." --severity medium`
2. Take a photo and attach it
3. If urgent: call lead staff immediately, don't wait for end-of-day report

---

## Notes

- "Done" means every checkbox above is completed, not just attempted
- Do not skip steps because the house "looks fine" — run the full checklist
- If a task cannot be completed, document why in the daily report
