# Housekeeper Playbook

**Type**: recurring  
**Owner**: Housekeeper  
**Properties**: all  
**Cadence**: daily tasks + weekly deep clean

This playbook defines exactly what clean looks like — per room, per task. There is no ambiguity. "I cleaned it" means every item below was completed.

---

## Daily Cleaning (2–3 hours, all properties)

### Bedrooms
- [ ] Make beds with tight corners — no wrinkles
- [ ] Fluff and arrange pillows in designated layout
- [ ] Clear all surfaces of clutter (nightstands, dresser)
- [ ] Dust visible surfaces if dusty to touch
- [ ] Open windows for 10 min air circulation (weather permitting)
- [ ] Vacuum or sweep if visibly dirty
- [ ] Empty trash bin

### Bathrooms
- [ ] Wipe sink, faucet, counter — dry finish, no streaks
- [ ] Clean toilet: seat, lid, bowl, base
- [ ] Wipe mirror — no water spots
- [ ] Wipe shower/tub surround — no soap scum visible
- [ ] Replace towels if used (fold replacements per standard: tri-fold, centered)
- [ ] Restock: toilet paper (min 2 rolls visible), hand soap (>25% full), tissues
- [ ] Empty trash bin
- [ ] Sweep/mop floor

### Kitchen
- [ ] Wipe all counters (including behind appliances)
- [ ] Clean stovetop — no residue, no grease
- [ ] Wipe exterior of microwave, oven, fridge
- [ ] Wipe cabinet fronts at eye level
- [ ] Clean sink — no food residue, polish chrome
- [ ] Sweep floor, spot mop if needed
- [ ] Take out trash and replace liner

### Common Areas (living room, dining, entry)
- [ ] Dust all horizontal surfaces
- [ ] Wipe glass surfaces and windows (touch points)
- [ ] Vacuum rugs and upholstered furniture
- [ ] Straighten all decor to standard placement
- [ ] Clean light switches, door handles (high-touch surfaces)
- [ ] Sweep/mop hard floors

---

## Weekly Deep Clean (4–6 hours, rotate by property)

### Bedrooms
- [ ] Strip and wash all bed linens (see Laundry section)
- [ ] Wipe all baseboards
- [ ] Clean under bed (vacuum, check for items)
- [ ] Clean inside closet — remove dust, straighten
- [ ] Wipe ceiling fan blades
- [ ] Clean windows inside

### Bathrooms
- [ ] Scrub tile grout
- [ ] Clean shower drain — remove hair and buildup
- [ ] Descale showerhead if needed
- [ ] Deep clean toilet tank exterior
- [ ] Wipe all cabinet interiors
- [ ] Wash bath mat

### Kitchen
- [ ] Clean inside microwave
- [ ] Clean inside oven (if used)
- [ ] Pull out appliances and clean behind
- [ ] Wipe inside fridge — remove all items, wipe shelves
- [ ] Clean exhaust fan filter (monthly)
- [ ] Deep clean sink drain
- [ ] Mop full floor (not spot)

### Common Areas
- [ ] Dust blinds and curtains
- [ ] Wipe all baseboards
- [ ] Clean windows inside and out (ground floor)
- [ ] Vacuum under furniture
- [ ] Polish wood furniture

## Laundry Workflow

**Before washing anything**: Check the care tag on every item first — fabric, color, and brand instructions vary, and washing on the wrong cycle or temperature can shrink, bleed, or damage the item. Sort and wash according to what each tag actually says rather than a single default cycle.

**Linens** (weekly):
1. Strip beds on assigned day
2. Check care tags — wash according to each item's tag (fabric/temperature/cycle)
3. Fold and return same day — beds made before EOD
4. Report any staining or damage immediately

**Towels** (2x per week when occupied):
1. Replace all used towels — even slightly used
2. Check care tags — wash according to each item's tag (fabric/temperature/cycle)
3. Fold per standard: tri-fold for hand towels, roll for bath towels

**Personal items** (resident laundry):
- Only touch if explicitly requested by resident
- Separate colors from whites — ask if uncertain
- Never use resident items for household tasks

## Standards

| Item | Standard |
|------|----------|
| Mirrors | No streaks — check from multiple angles |
| Counters | Dry, no residue, no fingerprints |
| Floors | No visible dirt, hair, or debris |
| Beds | Tight, even, no wrinkles in linens |
| Towels | Tri-folded or rolled, symmetrically placed |
| Trash | Empty before 50% full — never overflowing |

---

## Do's and Don'ts

**DO:**
- Follow the checklist — every item, every time
- Report issues immediately — broken items, damage, anything unusual
- Knock before entering any room
- Put things back exactly where they were found

**DON'T:**
- Read, touch, or move personal correspondence, devices, or documents
- Use household cleaning supplies for personal use
- Invite anyone onto the property without explicit permission
- Skip steps because you're running behind — flag the issue instead

---

## Issue Reporting

- Broken or damaged item: photo + MiHomes issue log within 2 hours
- Low supplies: text lead staff — don't wait until you run out
- Something that seems off (smell, water, structural): call lead staff immediately

---

## Verification

Housekeeper signs off via daily report. Lead staff does weekly spot check using room-by-room standards above. Photo documentation required for weekly deep clean.
