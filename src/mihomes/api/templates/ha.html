mihomes ha run

Add to cron or systemd for continuous monitoring. Sensor events that match rules will automatically create issues or alerts in MiHomes.

How It Works
  1. Bridge connects to HA WebSocket API and authenticates
  2. Subscribes to all state_changed events
  3. Each event is matched against sensor detection rules
  4. Matching events create Issues (physical problems) or Alerts (notifications)
  5. 5-minute cooldown prevents duplicate entries per sensor
  6. Issues appear on the Properties and Issues pages
  7. Alerts appear on the Alerts page with acknowledge/snooze actions
