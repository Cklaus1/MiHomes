  1. MiHomes runs as a Home Assistant add-on panel
  2. Supervisor injects credentials — no manual setup
  3. Real-time sensor events are matched against detection rules
  4. Matching events create Issues or Alerts in MiHomes, linked to the affected property
  5. AI analyzes patterns across all properties using the SPACE framework
  6. Tasks, work orders, and maintenance schedules are generated automatically
