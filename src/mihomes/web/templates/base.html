{# Sign out. `POST` with a CSRF token, never a link: a `GET /signout` can be triggered by any third-party page — an `` is enough — which is a nuisance rather than a breach, but a real one. The route has existed since SPEC-003 G12 and had **no way to reach it from the UI**, so the only way to end a session was to clear the cookie by hand. The token is read **from the request cookie**, not from a context variable: this layout is inherited by all 28 pages, and threading `csrf_token` through every route's context would mean touching 142 endpoints — with the one that forgets rendering a sign-out button that 403s. `mihomes_csrf` is `httpOnly=False` for exactly this purpose, since the page has to echo it back in a form field. #}
