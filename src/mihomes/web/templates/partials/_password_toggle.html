{# A Show/Hide button on every password field on the page. Included once per page, after the forms (`_auth_layout.html`, `settings/_personal.html`). Added by script rather than written beside each input: without JS the field is an ordinary password box, and a button that could do nothing would be the only thing on the page that lies. `aria-pressed` carries the state; the label stays "Show password" so a screen reader hears one control whose state changes, not a control that renames itself. #}
